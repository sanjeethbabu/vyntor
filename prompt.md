# MASTER PROMPT — VYNTOR TECHNOLOGIES CORPORATE WEBSITE

## 1. Project Overview

Build a complete, premium, modern, production-quality corporate website for **VYNTOR Technologies**, a technology company specializing in software development, artificial intelligence, SaaS products, automation, and digital solutions.

**Brand name:** VYNTOR Technologies  
**Brand identity:** Innovative, intelligent, ambitious, reliable, and globally competitive.  
**Brand philosophy:** Victory begins with an idea.  
**Primary tagline:** Innovating Your Vision.  
**Website type:** Premium IT services company and technology startup website.

The website must look like it was designed by a world-class branding agency and developed by an experienced senior frontend and full-stack engineering team.

Do not create a generic IT company template. Create a distinctive, recognizable digital identity that makes VYNTOR Technologies look trustworthy, innovative, technically advanced, and ready to serve startups, small businesses, and established enterprises.

## 2. Design Direction

Create a beautiful, light-themed website with a predominantly white background.

### Color palette
- Primary background: Pure white (#FFFFFF).
- Secondary backgrounds: Soft off-white (#F7F9FC) and subtle light gray.
- Primary text: Deep navy or near-black for excellent readability.
- Brand accent: Refined electric blue or royal blue.
- Secondary accent: Subtle violet or cyan, used sparingly for AI-related visuals.
- Borders: Very light gray.
- Gradients: Soft blue-to-violet gradients for selected visual elements.

Do not use a dark theme, black full-screen backgrounds, excessive gradients, or neon-heavy visuals.

Maintain a consistent color system, excellent contrast, generous whitespace, elegant typography, clean spacing, and balanced composition.

### Visual identity
Use the supplied VYNTOR Technologies logo as the primary brand asset. If no logo is provided, create a clean text-based brand treatment and a temporary logo placeholder without inventing a replacement brand identity.

Use a premium typography pairing, such as:
- Headings: Sora, Plus Jakarta Sans, or Manrope.
- Body text: Inter or a similarly readable modern sans-serif.

Use large, confident headings, carefully controlled font weights, refined letter spacing, and clear visual hierarchy.

The design should feel modern, premium, intelligent, and memorable rather than overly decorative.

## 3. Technology Stack

Choose a modern, maintainable stack suitable for a professional production website.

Preferred stack:
- Next.js with React and TypeScript.
- Tailwind CSS for styling.
- Framer Motion or Motion for React for animations.
- Lucide React for consistent icons.
- React components with reusable layouts and design tokens.

Use server components where appropriate, client components only when needed, and semantic HTML throughout.

Use a suitable contact-form backend or server-side integration if configuration is available. Keep credentials and API keys in environment variables.

Do not use Flutter for the main website unless there is a specific architectural reason to do so. Prioritize a fast, responsive web experience.

## 8. Animation and Interaction

The website should feel alive, polished, and responsive without becoming distracting.

Implement:
- Smooth page transitions where appropriate.
- Subtle hero entrance animations.
- Staggered card reveals.
- Elegant hover states.
- Animated buttons and navigation indicators.
- Gentle floating illustrations.
- Scroll-triggered section reveals.
- A refined mobile menu transition.
- Optional lightweight SVG-based AI network animation.

Use Motion for React or CSS animations where appropriate.

Requirements:
- Respect `prefers-reduced-motion`.
- Avoid excessive parallax and distracting scroll hijacking.
- Avoid forced loading animations.
- Do not delay access to essential content.
- Maintain smooth scrolling and stable layouts.
- Avoid animation libraries or effects that materially harm performance.

## 10. Technical Quality Requirements

The website must:
- Be fully responsive across desktop, tablet, and mobile.
- Use reusable components and maintainable architecture.
- Have semantic HTML and accessible navigation.
- Support keyboard navigation and visible focus states.
- Include descriptive image alt text.
- Use optimized images and appropriate modern formats.
- Avoid layout shifts and unnecessarily large bundles.
- Include loading, error, and empty states where relevant.
- Use SEO-friendly URLs and metadata.
- Include page titles, meta descriptions, canonical URLs where appropriate, Open Graph metadata, and social sharing images.
- Generate an XML sitemap and configure robots.txt.
- Include appropriate structured data for the real organization and its actual services.
- Include a custom 404 page.
- Handle environment variables securely.
- Avoid exposing API keys or secrets in client-side code.
- Include useful error handling and logging.
- Pass TypeScript checks, linting, and production build validation.

Use appropriate security controls, validation, and rate limiting for any backend functionality.

Do not add authentication, a database, or an admin dashboard unless there is a genuine requirement for them.

## 11. Performance and SEO

Aim for strong Core Web Vitals and high Lighthouse scores.

Prioritize:
- Fast initial rendering.
- Server-rendered content where beneficial.
- Optimized fonts and images.
- Minimal unnecessary JavaScript.
- Lazy loading for below-the-fold media.
- Accessible contrast and semantic structure.
- Crawlable content and internal links.
- Relevant page-specific metadata.

Do not sacrifice usability to achieve an artificial performance score.
